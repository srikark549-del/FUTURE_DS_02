# FUTURE_DS_02
# 📊 Customer Churn Analysis (Power BI)

## 🔍 Overview
This project analyzes customer churn behavior using Power BI to identify key factors affecting customer retention and provide actionable business insights.

---

## 🎯 Objectives
- Identify why customers are leaving  
- Analyze churn across different segments  
- Understand customer lifetime patterns  
- Provide recommendations to improve retention  

---

## 📁 Dataset
- Telco Customer Churn Dataset (Kaggle)

---

## 📊 Dashboard Features
- KPI Metrics:
  - Total Customers  
  - Churn Rate  
  - Retention Rate  
  - Average Tenure  

- Churn Analysis:
  - Contract Type  
  - Tenure Group  
  - Payment Method  

- Interactive Filters (Slicers)

---

## 📈 Key Insights
- Month-to-month contracts have the highest churn rate  
- Customers in the first 3 months are most likely to churn  
- Electronic check users show higher churn  
- Long-term customers show strong retention  

---

## 💡 Recommendations
- Encourage long-term subscriptions with discounts  
- Improve onboarding experience for new users  
- Target high-risk customers early  
- Promote automatic payment methods  

---

## 🛠️ Tools Used
- Power BI  
- Excel / CSV Dataset  

---

## 🚀 Outcome
This project demonstrates how data-driven insights can help businesses reduce churn and improve customer retention.
